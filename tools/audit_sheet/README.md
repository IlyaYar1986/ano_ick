# Сбор ответов «Практики 1.1: аудит задач»

Страница (`index.html`, блок 10) анонимно отправляет отметки участника в Google Форму «ИЦК — аудит задач преподавателя». Форма складывает ответы в таблицу «Ответы 1.1», лист «Ответы на форму (1)».

- Таблица: https://docs.google.com/spreadsheets/d/1dMvvAqnJ7loxq7mn7ryuoYPXAtbnPIT5708gIRYTLgM/edit
- Форма (редактор): https://docs.google.com/forms/d/124ECdx2uzlTBhB9Mmw6svSvnQSXFu5X0C0t7EzSM29k/edit

## Как отличить людей

Каждый браузер при первом заходе получает случайный номер. В столбце «Участник» он показан коротко, например `У-881b954c`. Форма умеет только добавлять строки, поэтому у участника, который передумывал, строк несколько: **актуальна последняя строка с его номером**. Один человек в двух разных браузерах или в режиме инкогнито будет посчитан дважды.

Страница отправляет ответ через 20 секунд после последнего изменения и сразу при закрытии вкладки. Пустые ответы не отправляются.

## Поля формы

Названия вопросов менять можно, удалять и добавлять нельзя: страница отправляет ответы по внутренним номерам полей (`AUDIT_FIELDS` в `index.html`).

| Вопрос | Поле |
|---|---|
| Участник | `entry.1910359267` |
| Специальность | `entry.270297146` |
| Отдать ИИ | `entry.1371561730` |
| Вместе | `entry.527206453` |
| Только я | `entry.248635769` |
| Свои задачи | `entry.482313376` |
| Данные (JSON) | `entry.1474192262` |

Если форму пересоздать, номера изменятся. Тогда их нужно заново взять со страницы `…/viewform` (массив `FB_PUBLIC_LOAD_DATA_`) и обновить `AUDIT_FIELDS`.

## Сводка

```bash
python3 tools/audit_sheet/svodka.py
```

Скрипт читает таблицу по ссылке (у неё открыт просмотр по ссылке), берёт последнюю строку каждого участника, пропускает тестовые строки, начинающиеся с «ТЕСТ», и печатает: число участников, специальности, подсчёт по каждой задаче и свои задачи участников.
