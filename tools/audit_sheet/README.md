# Сбор ответов «Практики 1.1: аудит задач» в Google Таблицу

Страница (`index.html`, блок 10) анонимно отправляет отметки участника в Google Таблицу автора курса.

- **Кто есть кто.** Каждый браузер при первом заходе получает случайный номер (`ick-audit-pid` в `localStorage`). Повторные изменения того же браузера обновляют его строку, а не добавляют новую. Поэтому в таблице разные люди — это разные строки.
- **Ограничение.** Один человек, открывший страницу в двух разных браузерах или в режиме инкогнито, будет посчитан дважды.
- **Что приходит:** номер браузера, необязательная специальность, отмеченные задачи, свои задачи. ФИО и контактов страница не собирает.

## Подключение (один раз, ~3 минуты)

1. Создайте новую Google Таблицу, например «ИЦК — аудит задач».
2. Меню **Расширения → Apps Script**. Удалите заготовку и вставьте содержимое `Code.gs` из этой папки. Сохраните.
3. **Начать развёртывание → Новое развёртывание**. Тип — **Веб-приложение**.
   - Запуск от имени: **Я**.
   - У кого есть доступ: **Все**.
4. Нажмите **Развернуть**, разрешите доступ к таблице и скопируйте **URL веб-приложения** (оканчивается на `/exec`).
5. Вставьте этот URL в `index.html`: `const AUDIT_ENDPOINT = '...';` — и выложите сайт.

Проверка: откройте URL веб-приложения в браузере — должно появиться `{"ok":true,"info":"Приём ответов аудита задач работает"}`.

## Что в таблице

- Лист **«Ответы»** — одна строка на участника: специальность, счётчики, списки задач по каждому варианту, свои задачи.
- Лист **«Сводка»** — по каждой задаче: сколько человек выбрали «Отдать ИИ», «Вместе», «Только я». Отсортировано по числу желающих работать с ИИ. Пересчитывается после каждой отправки.

## Если изменили `Code.gs`

Apps Script не обновляет работающее веб-приложение сам. Нужно **Начать развёртывание → Управление развёртываниями → карандаш → Версия: новая → Развернуть**. URL при этом не меняется.

## Безопасность

URL веб-приложения виден в коде страницы. Им можно только добавить или обновить строку ответа — прочитать таблицу или изменить что-то ещё через него нельзя. Тексты, начинающиеся с `=`, `+`, `-`, `@`, сохраняются как текст, а не как формулы.
