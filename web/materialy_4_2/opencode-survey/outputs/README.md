# Здесь появятся ваши результаты
Стартовый комплект не содержит готовых подтверждённых карточек и реальных логов.

После фактического интервью и явного подтверждения создаются:
- card_01.md, card_02.md, card_03.md;
- answers_01.md, answers_02.md, answers_03.md;
- summary.md — только после проверки наличия трёх карточек;
- rule-test-v1.md, rule-test-v2.md — только если вы сохранили реальные ответы своей модели в отдельном тесте.

Образцы формата находятся в examples/ и не считаются результатами запуска.
