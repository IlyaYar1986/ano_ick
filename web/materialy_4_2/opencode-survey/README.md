# opencode-survey · агент-опросник для студентов СПО

Все данные синтетические. Папка содержит стартовые материалы, но не результаты живого запуска. Примеры в examples/ составлены автором и подписаны отдельно.

## Подготовка среды для самостоятельного повторения

Нужны Node.js LTS с npm, OpenCode 1, терминал, текстовый редактор и разрешённый доступ к модели с чтением/записью локальных файлов. Развёрнутые шаги курса: https://ilyayar1986.github.io/ano_ick/web/praktika_3_4.html . Страница практики 4.2 с теми же запросами: планируемая https://ilyayar1986.github.io/ano_ick/web/praktika_4_2.html (публикация этого пакета пока не выполнена).

1. Установите Node.js LTS с https://nodejs.org/en/download , заново откройте терминал.
2. macOS Terminal: `node --version`, `npm --version`, `npm install -g opencode-ai@1`, `opencode --version`.
3. Windows PowerShell: `node --version`, `npm.cmd --version`, `npm.cmd install -g opencode-ai@1`, `opencode --version`. npm.cmd позволяет не менять политику выполнения PowerShell. При несовместимости используйте маршрут Windows/WSL из темы 3.4 и https://docs.opencode.ai/docs/windows/ .
4. Убедитесь, что версия OpenCode начинается с 1. Это маршрут курса; OpenCode 2 тоже использует команду opencode. Если у вас другая версия, не заменяйте её посреди работы: сначала сверяйте инструкции https://docs.opencode.ai/docs/ .
5. Распакуйте ZIP. Откройте терминал в opencode-survey, где лежат AGENTS.md и questions.md. Пример macOS: `cd "$HOME/Downloads/opencode-survey"`; Windows: `Set-Location "$HOME\Downloads\opencode-survey"`. Если архив создал лишний уровень папки, откройте внутреннюю opencode-survey.
6. Выполните `opencode`, затем `/connect`, выберите своего провайдера и его способ авторизации. Затем `/models`, выберите доступную модель. Право доступа и условия провайдера должны быть проверены заранее; ключи не записываются в учебные файлы. Настройка: https://docs.opencode.ai/docs/providers/ .
7. Запросите «Прочитай AGENTS.md и questions.md; назови свою роль и ограничения записи файлов». Это проверка чтения; затем новая сессия `/new`. Для создания файлов используйте режим с разрешённой записью (Build); Plan предназначен для анализа. Не запускайте `/init`: готовые правила уже включены.

## Как повторить

Откройте prompts.md. P01 — необязательный контрастный опыт в отдельной пустой папке. P02 — полное интервью 01; ответы по одной реплике из respondents/01_electrician.md. P07 — исправление карточки; после обновлённого показа явно подтвердите её и подайте P08a. В новых сессиях: P05 → реплики 02 → подтверждение → P08b; P06 → P04 → реплики 03 → подтверждение → P08c. Затем P09 создаёт сводку, P13 помогает сверить её по источникам.

Для изменения поведения: новая сессия → P10, затем P11; новая сессия → тот же P10. Только фактические ответы своей модели можно вручную сохранить в outputs/rule-test-v1.md и outputs/rule-test-v2.md. P12 переносит опрос на логистику; ответ студента подаётся отдельно. Предыдущие карточки не используются как ответы нового студента.

Откройте сохранённые Markdown-файлы в редакторе и сопоставьте с исходными словами. Карточка без подтверждения не готова к сводке. Сводка по трём синтетическим сценариям не описывает реальную группу.

## Если что-то пошло не так

- Команда не найдена: завершите установку, заново откройте терминал, проверьте путь и шаги темы 3.4.
- Ошибка авторизации/квоты: проверьте провайдера и доступную модель; содержание учебного файла не решает проблему доступа.
- Не видит AGENTS.md: проверьте открытую папку, явный запрос чтения и начните `/new`.
- Выдал несколько вопросов: укажите нарушение и попросите один текущий вопрос; при повторении уточните правило и начните новый тест.
- Придумал роль или ответ: вернитесь к фактической реплике, восстановите «нет данных», снова покажите карточку и подтвердите её.
- Не создаёт файл: проверьте режим Build и разрешение записи в текущей папке; текст в чате не считается сохранённым файлом.
- Нет карточки/подтверждения: завершите нужное интервью, не используйте examples/ вместо результата.

Ни сервер, ни Python, ни MCP, ни расширения для этого проекта не требуются. Официальная документация: https://docs.opencode.ai/docs/ , https://docs.opencode.ai/docs/tui/ , https://docs.opencode.ai/docs/rules/ .
