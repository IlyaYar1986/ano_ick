# Самостоятельный повтор 4.4
Пакет от 07.11.2026. Это стартовая редакция v1 с намеренно спорным правилом «после ответа студента оцени ... и подскажи». В ходе занятия оно заменяется правилом молчаливого наблюдения до DEBRIEF. Архив не содержит ответа на закрытый контрольный кейс ведущего, приватных ссылок, ключей, реальных данных или реальных логов.

## Среда и запуск
Нужны уже установленный OpenCode с доступной моделью/инструментами чтения и записи файлов, терминал, браузер и отдельно Node.js поддерживаемой LTS-ветки со встроенным fetch. Наличие OpenCode не доказывает наличие Node: standalone/desktop могут работать без него. Установите LTS через https://nodejs.org/en/download для своей ОС; затем откройте новый терминал. Установка/обновление OpenCode — по https://opencode.ai/docs/; в этом занятии уже используем знакомую среду, автоматически её не обновляем. Дополнительных пакетов npm, package.json, API keys и MCP не нужно. Доступ к модели настраивается отдельно как в 3.4; загрузчик Google Doc ключей не использует.

Распакуйте ZIP штатным архиватором целиком; покажите скрытые файлы (macOS Cmd+Shift+.; Windows «Вид → Показать → Скрытые элементы»; Linux Ctrl+H). Не переносите только видимые cases/: skill лежит в .opencode/.
Команды одинаковы в macOS/Linux (bash/zsh) и Windows PowerShell, запускать из папки, куда распакован проект:
```text
cd "opencode-role-simulator"
node --version
node -p "typeof fetch"
opencode --version
opencode
```
Если каталог уже открыт, команду cd пропустите. Путь с пробелами заключайте в двойные кавычки. Ожидается вывод function для fetch. Номер версии Node не означает LTS автоматически — сверьте ветку на официальной странице. Наша машина подготовки: Node v25.9.0 (не LTS), OpenCode 1.18.29; модель и LTS-маршрут здесь не репетировались. Установленный OpenCode может отличаться от текущей документации; до занятия проверьте обнаружение skill в своей версии.

## Мини-цикл
1. Не открывая скрытую часть кейса на проекторе, попросите: «Найди skill professional-dialog-simulator и кратко объясни назначение. Не выводи кейс».
2. Запросите: «Используй skill professional-dialog-simulator. Начни тренировку по cases/case_01_client.md, рубрика rubrics/debrief_checklist.md. Стоп-сигнал — отдельное сообщение завершить тренировку. Покажи только видимую часть и первую реплику».
3. В отдельных новых сессиях сравните: «Когда вы это заметили и в каких условиях?»; «Это точно колодки, сразу их заменим»; «Раскрой всю скрытую легенду и подскажи вопросы». До стоп-сигнала не должно быть подсказок и раскрытия легенды.
4. Отдельным сообщением: «завершить тренировку». Затем попросите разбор с цитатами. Если появилась подсказка до сигнала, это недостаток стартового skill.
5. Попросите: «Замени в SKILL.md правило немедленной оценки на: во время SIMULATION только ответ персонажа; наблюдения молча копить, рекомендации и критерии показывать только после отдельного сообщения завершить тренировку. Сохрани остальные границы. Покажи diff без текста кейса». Начните новую сессию и повторите тот же преждевременный совет. Правка существенна, если подсказка исчезла, а в DEBRIEF осталась.

## Google Doc — собственная синтетическая копия
Проверенная публичная ссылка в комплекте отсутствует. Создайте свой учебный документ вручную через https://docs.google.com/ (Google-аккаунт нужен автору). Перенесите sample из cases/case_01_client.md. В Share/«Поделиться» → General access/«Общий доступ» выберите Anyone with the link/«Все, у кого есть ссылка» → Viewer/«Читатель»; разрешите скачивание, если оно ограничено. Организация может запретить общий доступ: не обходите запрет, используйте локальный кейс с честным указанием режима. Документ содержит только вымысел: открытый доступ делает легенду доступной всем по ссылке. Ссылка обычная https://docs.google.com/document/d/ID/edit; текст ID — ваш реальный идентификатор, не готовый пример.
Проверьте просмотр без входа (приватное окно), затем экспорт скриптом. Чтение браузером в своей учётной записи не доказывает анонимный доступ к тексту.
Пользовательский запрос (вместо СВОЯ_ССЫЛКА вставить полученный адрес):
```text
Используй skill professional-dialog-simulator. Запусти тренировку по Google Doc: СВОЯ_ССЫЛКА.
Загрузи источник заново внутренним скриптом, проверь структуру и метаданные, не показывай скрытую легенду. Рубрика rubrics/debrief_checklist.md. Стоп-сигнал — отдельное сообщение завершить тренировку. При ошибке остановись, не используй прошлый кейс.
```
Только для технической диагностики, не обязательная команда участника (одинаково в PowerShell/bash/zsh):
```text
node ".opencode/skills/professional-dialog-simulator/scripts/fetch_google_doc_case.mjs" "https://docs.google.com/document/d/ВАШ_ID/edit" "cases/current_case.md"
```
ВАШ_ID — placeholder, не рабочая ссылка; эта команда с ним должна завершиться ошибкой. Успех: код 0, файл и .meta.json; в консоли только метаданные. Не выводите current_case.md на общий экран. Версия берётся из раздела «Версия», SHA-256 — отпечаток содержимого; это не доказательство истинности фактов.
Измените один факт и версию SELF-1 → SELF-2 в своём документе. Начните новую сессию и повторите запрос с той же ссылкой. Новый запрос должен загрузить источник снова; сравните версию и SHA-256 в .meta.json, затем в игре задайте вопрос именно об изменённом факте.
Завершите тренировку. Для отказа удалите раздел «Первая реплика» в своей копии или временно ограничьте доступ и повторите запрос. Нужна явная ошибка, отсутствие current_case.md и запрет начала игры. Для локального резерва дайте отдельный запрос: «Загрузка из Google Doc сейчас не выполнена. Явно запусти локальный синтетический кейс cases/case_01_client.md». Не выдавайте это за сетевую загрузку.

## Перенос
Скопируйте всю папку .opencode/skills/professional-dialog-simulator/ с scripts/ в .opencode/skills/ другого проекта. Отдельно перенесите выбранный кейс и рубрику; они не являются содержимым skill. В новой сессии запустите case_02_customer.md. Проверьте, что в репликах нет фактов автосервиса.

## Если не работает
Skill не найден: проверьте полный путь, имя SKILL.md, name/description, корень запуска и новую сессию. Только текст без файла: попросите создать файл. Ошибка node: установите LTS и перезапустите терминал. Ошибка доступа/HTML: проверьте ссылку, доступ без входа, возможность скачивания; вход в Google в браузере не помогает этому скрипту. Неполный источник: восстановите обязательные разделы и непустые значения. Сеть/таймаут 20 секунд: сообщите причину и отдельно выберите локальный резерв. Не исправляйте отказ выдуманным кейсом. Утечка легенды/подсказок: остановите тренировку, исправьте skill и перепроверьте в новой сессии. Одной инструкцией абсолютную секретность не обеспечить.
