# Материалы слушателю: долгосрочные процедуры

Два независимых проекта: преподаватель готовит доступное занятие и улучшает план по наблюдению; студент разбирает готовый текст, сохраняет трудность и возвращается к ней в новом диалоге.

Все события и даты внутри примеров синтетические. Реальные персональные и медицинские данные не используются. Проект работает с текстом; распознавание аудио, диагностика, фоновое расписание и уведомления не реализованы.

## С чего начать

1. Извлеките архив полностью. Для первого цикла откройте папку opencode-ovz-teacher с AGENTS.md непосредственно в корне; затем отдельно opencode-ovz-student.
2. Для самостоятельного повторения нужна установленная среда OpenCode, интернет и доступ к модели. Подробная справка курса: ../praktika_3_4.html при просмотре сайта. Официальная установка OpenCode 1: https://docs.opencode.ai/docs/; Windows: https://docs.opencode.ai/docs/windows-wsl/. Обе основные версии имеют команду opencode; не ставьте другую поверх рабочей без выбора версии.
3. В Windows откройте PowerShell из адресной строки распакованной папки; на Mac в Терминале наберите cd и перетащите папку. Выполните opencode --version, затем opencode. Для OpenCode 1 подключите модель /connect и выберите /models. Ключи в файлы не записывайте.
4. Читайте Промпты_слушателю.md: T0–T2 в teacher; S0–S3 в student; N1 в новых диалогах; затем T3/S4 и повтор N1. В комплекте есть рабочий AGENTS.md студента; S0 демонстрирует создание новой редакции через требования. Проверьте её по S1 и начните новый диалог.
5. До/после сравнивайте examples/state_00.md, state_01.md и state_02.md. Это образцы, а не ваш прогресс. Текущая работа сохраняется в state.md, журналах и outputs/.
6. Для нового запуска в OpenCode 1: /exit → opencode → /new. Не выбирайте старую сессию и не используйте /compact как замену новому диалогу. Отправьте N1, проверьте пути и цитаты.

## Критерий результата

Сохранены исходный текст и старые версии; есть цитата наблюдения/трудности; новый срок 12 ноября; история прежнего срока 10 ноября; завершённое не стёрто; следующий шаг соответствует роли; подготовка не названа освоением. После N1 новый диалог воспроизводит это по рабочим файлам. Итоговые отчёты outputs/report_v1.md можно сохранить вместе с проектом.

При ошибке укажите конкретную строку и файл; запросите минимальную правку с сохранением предыдущей версии. Если источник отсутствует — восстановите его из чистого ZIP, а не просите выдумать содержание. Если модель не подключена — завершённый ответ не будет получен; образцы можно открыть для изучения, называя их синтетическими.
