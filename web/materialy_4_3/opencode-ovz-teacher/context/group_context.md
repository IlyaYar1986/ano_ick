# Обобщённый учебный контекст
СИНТЕТИЧЕСКИЕ УЧЕБНЫЕ ДАННЫЕ. Условные события; реальные занятия, люди и многонедельная история не описываются.
Группа: условный 2 курс СПО, электромонтаж. Имена, диагнозы и индивидуальные характеристики не используются.
Барьер: длинная устная инструкция теряется; два близких термина могут смешиваться. Полезны короткие смысловые блоки, схема и один вопрос после блока. Это учебная гипотеза для проверки преподавателем, а не медицинская характеристика.
Формат: разбор текста, занятие 45 минут. Доступны доска, проектор, распечатка на одну страницу. Реального выполнения работ в упражнении нет.
