# Проект преподавателя
СИНТЕТИЧЕСКИЕ УЧЕБНЫЕ ДАННЫЕ. Условные события; реальные занятия, люди и многонедельная история не описываются.

1. Распакуйте ZIP полностью. Откройте эту папку, где непосредственно лежит AGENTS.md.
2. Запустите `opencode`; подключите доступную модель (`/connect`, затем `/models` для OpenCode 1). Вводите запросы из Промпты.md или учебной страницы.
3. Сначала прочитайте state.md и входные файлы. Стартовая версия — 00. В outputs/ нет результата процедуры.
4. Выполняйте запросы по очереди; проверяйте файлы после записи. В examples/ лежат только синтетические образцы до/после; агент не должен принимать их за журнал выполненной работы.
5. Для проверки продолжения выйдите через `/exit`, снова запустите `opencode` в этой папке и явно создайте новый диалог (`/new` в OpenCode 1), не выбирайте старую сессию.
6. На Windows откройте PowerShell из адресной строки папки; на macOS в Терминале введите `cd ` и перетащите папку. Если CLI ещё не установлен, используйте установку из темы 3.4 или https://docs.opencode.ai/docs/ (OpenCode 1).

Названия ovz сохранены из исходного упражнения; файлы описывают учебные барьеры и предпочтения, без диагнозов. Проекты разных ролей не объединять. Ключи API в папку не сохранять.

## Установка для самостоятельного старта

Рабочая ветка инструкции — OpenCode 1. Windows/macOS: установите Node.js LTS с https://nodejs.org/en/download; откройте новый терминал; проверьте `node --version` и `npm --version`; выполните `npm install -g opencode-ai`, затем `opencode --version`. Для Windows при блокировке npm.ps1 используйте `npm.cmd install -g opencode-ai`. Официальная документация: https://docs.opencode.ai/docs/. OpenCode 2 имеет другой пакет и ту же команду; не заменяйте установленную среду без выбора версии. Подключите своего провайдера через `/connect`, модель через `/models`. В режиме Plan файл может не записываться — выберите режим с записью, например Build.
